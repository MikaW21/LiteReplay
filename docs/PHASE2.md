# Phase 2c 媒体库状态

软件由 Yuzi_Lj 制作。2026-11-09。

继承自动回放入库、手动导入 MP4/MKV/MOV、按日期/类型筛选、搜索、重命名、删除/移除、文件位置、内嵌 MFPlay 预览。主程序按需加载预览，切页/最小化/托盘隐藏时 Shutdown。索引仍使用版本化的原子提交文件，不持续扫描目录，最多 10000 项、32 MiB 索引。

本次补齐选中项缩略图的主动生成。400ms 选择防抖后启动一个同 EXE 的内部工作模式；用户无需启动第二个软件。使用 Shell 系统提取器，要求真缩略图，不能以文件图标冒充。共享像素区固定为 192×108×4 加尺寸头。子进程以挂起状态创建，加入 kill-on-close Job 后运行，低优先级，10 秒超时，界面仅在活动任务期间每 200ms 检查完成。切换选择、离开页面、删除或重命名前取消；预览开始前取消未完成提取。任务崩溃或失败不会以成功位图显示。

内存 LRU 按路径、大小、修改时间组成键。最多 128 项（含负缓存），并遵守模式像素预算 8/32/64 MiB；实际可因条目上限更小。负缓存避免反复解码失败项，点击刷新会失效当前键。离开页面清空，不引入新的持久缩略图目录。系统 Shell 可能使用自己的磁盘缓存和 COM 代理，这些资源不能从性能统计中忽略。

此实现仍是列表和单项缩略图，不是完整缩略图网格。没有通用解码回退，缺少对应系统提取器会显示不可用。源文件在外部改变后需刷新。慢盘文件属性读取、Shell 文件操作和索引写入仍可能阻塞 UI。完整编码格式/音轨元数据、工程引用和剪辑入口未完成。

验收：导入中文路径/损坏视频/系统不支持格式；快速切换条目不得显示上一条结果；重复选取缓存项不启动新任务；刷新重新提取；提取中切页、最小化和退出，检查子进程回收；预览期间不重复提取；低资源模式缩减缓存；原文件无变化。所有这些 Windows 运行项尚未执行。

AMD/Intel 兼容后端已由 Compatibility Preview 引入，不再有原先 NVIDIA-only 输出过滤；驱动兼容仍待实际验证。见 COMPATIBILITY.md。
