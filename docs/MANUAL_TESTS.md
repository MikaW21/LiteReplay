# Windows 实机验收与性能测试

所有结果请实填。此文件是待执行的测试计划，不是成功报告。

## 记录环境

记录 Windows build、GPU 型号/驱动、CPU、RAM、显示器刷新率/缩放/HDR、显示器与 GPU 连接、声音设备、游戏版本、FFmpeg / vcpkg commit。使用本地 SSD 输出，先关闭 GG/Moments、ShadowPlay 等其他录制器。保持电源和游戏画质设置一致。

## 最小功能验收

1. 构建脚本成功并生成含依赖的发行目录；保存构建日志和 BUILD_INFO。
2. LiteReplayProbe 默认运行报告 H.264/HEVC/AV1 NVENC、AAC 存在。此步骤不是硬件运行证明。
3. `LiteReplayProbe --capture`：输出约 5 秒视频并能播放系统声音，确认不是黑屏、比例/色彩正常。
4. GUI 1080p60 H.264，缓存 30 秒，运行 45 秒，按默认热键保存；验证 MP4、MKV 各一份。
5. 1440p60、1080p30、1440p30；每种编码分别保存。编码能力失败必须明确报错，不能在后台切软件编码。
6. 同时播放游戏、QQ、Discord 的声音，全部路由到同一个默认耳机设备；回放应都可听见。把一项改到另一设备，确认这部分不会被录入，并与文档一致。
7. 麦克风开/关、混合/独立轨道；独立轨道应有 1 路视频 + 2 路 AAC。仅麦克风并选择分轨时第一条声音轨可能为静音，切第二轨检查。
8. 连按保存快捷键；同一时间只允许一个保存，不形成无限任务队列。保存完成后再次保存。
9. 修改路径为含中文和空格的本地目录；修改文件名前缀；重复文件名不覆盖已有视频。
10. 缓存设置 600 秒 / 128 MiB，高码率录制：容量达到上限后实际时长变短，但首帧仍可解码。

每段视频执行：

```powershell
python .\scripts\verify_replay.py 'C:\clips\test.mp4' --audio-tracks 1 --json result.json
ffmpeg -v error -i 'C:\clips\test.mp4' -map 0:v -map 0:a? -f null NUL
```

正常情况下第一视频包为关键帧，每流 DTS 严格增加、没有负时间戳/空轨。
默认检查器端点容差为 250 ms，用来发现结构性错误；它不是内容同步的合格标准。

## 音画同步验收

使用本地可重复播放的闪光/短音测试片，或显示击发与发声同时发生的测试场景。不要凭网络视频缓冲判断录制同步。

- 在视频编辑器中定位白闪帧和声音波形峰值，测量偏移；先测源视频偏移作为基线。
- 分别测试运行 1 分钟、30 分钟、120 分钟后的回放。
- 记录开始/中段/末尾偏移，区分固定输出延迟与随时间累积的漂移。
- 建议首轮目标：相对源片偏移在 ±50 ms 内，2 小时测试没有持续增长趋势；这是验收目标，当前没有测试结果。
- 更换采样率 44.1k/48k/96k，播放设备/麦克风使用不同采样率；切换设备后允许短静音，但之后应回到同步。

## 恢复与异常

| 场景 | 应观察的结果 |
|---|---|
| 连续 Alt+Tab 20 次，退出/重启游戏 | UI/热键可用，显示器捕获继续或自动恢复 |
| 独占全屏/无边框各一轮 | 记录支持情况，不把全黑视作成功 |
| 锁屏/解锁、休眠/唤醒、拔插显示器 | 自动重建；旧未保存缓存允许丢失；不跨编码会话拼接 |
| 默认耳机切换、拔出麦克风 | 日志出现重连；短静音后恢复，无无限队列增长 |
| 保存中继续录制 | 下一份回放仍含期间内容，保存写盘未停止捕获 |
| 输出目录只读 / 磁盘接近满 | 保存报错，UI 可用；正常错误路径清理 partial |
| 任务管理器强制结束 | 不遗留 LiteReplay 子进程；partial 可手动删除 |
| 热键被其他软件占用 | 明确报错，可改热键，不假装注册成功 |
| 托盘退出/注销系统 | 所有线程结束；无额外服务/进程 |
| H.264 / HEVC / AV1 编码不支持 | 清楚错误并退避重试，不使用 CPU 视频编码 |

驱动重置测试可在专门的测试会话中尝试 Windows 的显卡驱动恢复快捷键，并观察恢复；该快捷键不等价于所有 TDR 故障，不能替代正式驱动异常测试。

## 两小时稳定性

分别运行内存缓存 30 秒、600 秒、麦克风混音和分轨组合；每 2 分钟保存一次，定期切换窗口/音频。
记录私有内存、工作集、句柄数、线程数、GPU 专用内存和视频编码使用率。

缓存填充阶段增长正常；完成填充后应达到稳定范围。保存期间由于共享快照保留旧包可短时升高，保存结束后应回落。评估长期斜率和资源计数，不能仅以一次内存截图判定泄漏。

```powershell
.\scripts\measure.ps1 -Seconds 7200 -Output '.\metrics-2h.csv'
```

采样 CSV 没有预填性能结果；GPU 指标在应用/任务管理器读取，也可以使用 Windows 性能计数器。
