# LiteReplay 2.0 Editor Preview 3

软件由 Yuzi_Lj 制作 · 2026-11-14

## 导出修复
- 保存路径选择改用 Windows IFileSaveDialog，由应用顶层窗口管理；之前使用嵌入式面板作为父窗口。
- 默认填入带时间戳的新文件名；用户可以修改。取消与错误分开处理，错误显示在主窗口并写入 editor-operation.log。
- 旧打开文件窗口保留，但增加扩展错误检查并使用顶层窗口。
- 重编码导出读取 FFmpeg 的实际 out_time_us 进度，显示百分比、已用秒数和目标路径；最终拼接/检查阶段进度可能短暂停留90%。快速裁剪仍只在完成时更新百分比，但显示运行时间。
- 硬件初始化、磁盘或编码错误会明确显示；日志附错误原因。
- 保持不覆盖原片和已有输出文件。若目标已存在，请换一个文件名。

用户报告的“点保存没有反应”未能在本Linux环境直接复现。上述修改修复已识别的对话框归属、静默错误及进度缺失问题，是否解决该机器的原问题仍需Windows复测。

## 即时回放音量
在“即时回放”页面，两路开关右侧分别填写系统声音和麦克风音量，点击“应用录制音量”。
- 0%=静音，100%=原始音量，200%=两倍幅度；过高增益会限幅，可能失真。
- 设置持久化；运行中可以应用，无需停止回放，不清空缓存。
- 仅作用于应用后新采集的音频，已缓存的旧音频保持原样。
- 混合轨、独立麦克风轨均应用对应增益。
- 不改变Windows设备/应用音量，也不能开启未勾选的音源。音源启停仍需停止回放后设置。

## 剪辑页布局
左侧片段列表、中间预览、右侧导出参数，底部独立裁剪行及更高的时间轴；时间轴标注片段文件名和开始时间。
新增音量文字支持中英切换。保留截图、剪贴板及HF2预览修复。

## 验证
Windows x64交叉构建及可移植逻辑测试通过。新增测试覆盖音量默认值/静音/独立增益/混合/限幅/异常浮点数，以及FFmpeg进度分块解析、CRLF、不完整与错误输出。主机FFmpeg测试覆盖裁剪、拼接、音量、成片解码和文件保护。
详见 validation/editor3-build.log、validation/editor3-tests.log；复现命令：python3 scripts/test-editor3.py。
Windows保存窗口、系统音频采集实际响度、运行中增益、NVENC导出及小屏/高DPI界面均未实机验证。
剪辑导出仍提供NVENC或CPU MPEG-4；AMD笔记本可选择CPU兼容导出，回放AMD兼容不代表剪辑已有AMF导出。BGM、字幕、多轨、代理与变速仍未完成。

## Windows复测步骤
1. 退出旧版（含托盘），解压新目录，运行 bin/windows-x64/LiteReplay.exe，确认标题 Editor Preview 3。
2. 导入10秒视频，导出到桌面新文件名。核对保存窗口关闭、进度变化、完成文件可播放。NVIDIA之外设备先选CPU MPEG-4兼容导出。
3. 再试中文目录、取消、已有文件名及无写权限目录；取消应返回编辑器，错误应有弹窗。
4. 系统声/麦克风设100%，录制中改为50%/0%并应用，再保存回放；比较修改前后新录制部分。另测试独立麦克风轨。
5. 若仍失败，提供窗口截图及 %LOCALAPPDATA%\LiteReplay\2.0\editor-operation.log、editor-export.log（存在的日志即可）。
