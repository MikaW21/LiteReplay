# LiteReplay 2.0 UI Preview 1 · 2026-11-13

软件由 Yuzi_Lj 制作 / Software by Yuzi_Lj

## 本版变化

- 原生 Win32/GDI 统一石墨色背景、分区边框与青绿色主按钮。按钮保留原生键盘、点击、焦点及控件身份，不引入浏览器或动画定时器。
- 左侧导航有当前页面状态；顶部统一显示页面标题与中英文说明。
- 首页分为即时回放状态、CPU/GPU/RAM 数值、创作入口。数据仍来自原有 Performance 接口，不显示模拟曲线；无数据时 N/A。
- 首页可直接启停回放、保存回放、进入设置/剪辑/媒体库。保存按钮在未开启回放时禁用。
- 回放设置、通用设置和监控页添加分区卡片；媒体库共享主导航与按钮外观。
- 剪辑页调整为工程工具栏、素材列表、预览、裁剪参数、时间轴、导出区。预览空闲提示不触发解码。
- 窗口默认 1360×920，可缩放；剪辑面板随可用尺寸扩展。小窗口保留滚动访问，最小剪辑内容宽 1100、高 840。尚非全控件自适应流式布局。
- 修正语言文件中仍称“剪辑尚未实现”的首页旧说明。

## 安装和复测

退出旧版，包括托盘。完整解压本包到新目录，运行 bin/windows-x64/LiteReplay.exe。窗口标题应为 LiteReplay 2.0 UI Preview 1 — Yuzi_Lj。必须保留 DLL、languages、editor-tools 等目录。使用原来的用户配置，不自动更改原视频或工程。

1. 首页开关回放、保存录像，确认媒体库新增文件；真实测试需支持的 GPU/驱动。
2. 点击全部导航，确认选中状态及每页内容；切换中英文，检查说明和按钮。
3. 调整窗口大小，尤其 1366×768 屏幕：使用滚动条访问下方及右侧控件。检查 Windows 100%、125%、150% 缩放。
4. 剪辑页导入、预览、设置入出点、分割、保存工程、导出；预览沿用 HF2，不调用 SetStartStopPosition。
5. 检查键盘 Tab 焦点、空格/Enter 按钮操作、禁用状态、托盘恢复和截图快捷键。

## 已验证及限制

25 条可移植构建/测试命令通过（12 个 C++ 测试程序、7 个 Python 用例）。Windows x64 使用 MinGW GCC 14 POSIX 交叉构建；结果见 validation/ui1-windows-build.log。录制引擎源码与 FFmpeg DLL 相对 HF2 保持不变。

当前环境没有执行 Windows UI，没有真实截图或 Windows 控件排版验收，也没有 CPU/GPU/内存性能测量。构建通过不等于实机功能通过。系统下拉框、复选框、文件对话框保留 Windows 原生外观；音频控制台内部布局与 HUD 尚未全面重做。背景卡片和按钮仅在重绘事件中绘制；不能据此宣称达到固定占用。

此版本仅升级界面。P3 背景音乐、字幕、变速、代理预览、多轨等仍未实现。HF2 预览末尾停止由定时器控制，非逐帧精确；导出流程未改。
