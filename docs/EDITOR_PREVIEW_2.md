# LiteReplay 2.0 Editor Preview 2

软件由 Yuzi_Lj 制作。2026-11-14。

## 本次改进
- 拖动时间轴或进度条后按需初始化暂停预览，打开文件时保留选择的定位时间。
- 裁剪片段进度条只映射有效入点至出点；播放结束后再次播放从入点开始。
- 连续预览从当前片段依次播放到工程末尾；切换片段重新打开播放器，可能有间隙，不保证无缝或逐帧切换。
- 增加 ±0.1 秒定位按钮；非输入框内支持空格播放/暂停、左右键微调、I/O 设置入出点、S 分割。0.1 秒定位不是逐帧定位，实际精度由系统解码器决定。
- 保存工程、常规导出、快速裁剪之前自动应用当前入出点/音量，防止忘记点“应用裁剪”。切换片段前仍请应用编辑。
- 重编码缩放改为 Lanczos；推荐码率按输出分辨率和帧率填入，可继续手动修改。1080p60 推荐28 Mbps，1440p60推荐48 Mbps；文件可能更大。CPU MPEG-4兼容导出仍使用固定质量，码率输入不生效。
- 标题显示 Editor Preview 2；保留 HF2（不调用 SetStartStopPosition）、截图/剪贴板、媒体库与回放兼容路径。

## 使用
完整解压，退出旧版和托盘进程，运行 bin/windows-x64/LiteReplay.exe。
先停止回放再剪辑。导入后拖动时间轴查看切点，I/O标记，应用裁剪；连续预览检查拼接顺序，选择输出参数并点推荐码率后导出。

## 验证及限制
Windows x64交叉编译通过；可移植逻辑测试及主机FFmpeg实际裁剪、拼接、声音处理、解码与不覆盖原片测试见 validation/editor2-tests.log。
Windows UI/暂停定位/连续预览/显卡编码未实机测试，不据此声称体验或画质已达标。真实媒体测试使用Linux FFmpeg和CPU编码，不等同于Windows/NVENC测试。
连续预览不是完整工程渲染预览，输出尺寸在导出时应用；超过100%的音量在系统预览中仍上限100%，导出使用设置值。
尚无BGM、字幕、多轨、代理与变速。剪辑导出仍为NVENC或CPU MPEG-4；回放AMD兼容不代表剪辑器已有AMF导出。

## Windows复测
1. 导入同一录像，未播放时拖到中间；核对暂停画面与播放头。
2. 设置入点20秒/出点30秒并应用，进度条两端应对应20/30秒。
3. 导入两个片段，选择第一段并连续预览，检查自动切换和音画同步。
4. 修改入出点但不点应用，保存工程后重开、导出并检查时长。
5. 测试截图粘贴、回放启停、窗口缩放；报告失败操作及 editor-preview.log/editor-export.log。
