# 截图使用与验收

软件由 Yuzi_Lj 制作 / Software by Yuzi_Lj

## 操作

设置页滚动到截图区域。点击快捷键输入框按组合键，分别设置快速截图与区域截图后点击保存。默认 Ctrl+Shift+F11 / Ctrl+Shift+F8。快捷键独立于回放保存键。设置保存在统一 settings.ini 的 Screenshots 区段。按键需带 Ctrl、Shift 或 Alt；Win 键组合当前不支持。

快速模式保存所有屏幕组成的虚拟桌面；多屏之间的空隙也在矩形图像内。区域模式在按键时冻结画面，可正向或反向拖选，松开保存。单击没有面积不保存。Esc、右键、焦点切换和显示器布局改变会取消。截图不包含区域选择框与提示文字，也不添加作者水印。不主动绘制鼠标指针。

保存为 PNG，目标为回放已应用路径下 Screenshots。名称含本地日期时间与 GUID 防止碰撞。写入 .partial 后以不覆盖方式改名。正常写入失败清理临时文件；进程被强制结束可能遗留 .partial，可在退出后手动删除。PNG 成功提交后自动登记到媒体库；失败的 partial 文件不会入库。旧截图可手动导入。

## 开销与限制

仅按键触发一次 GDI 桌面读取，回放仍使用原 GPU 路径。一次只允许一个框选或写入任务，避免连按无限排队。像素缓冲上限 64 MiB，过大虚拟桌面会报错；截取位图、原始像素和裁剪副本会短暂同时存在，此值不是总进程内存上限。PNG 写入线程使用低优先级，退出程序等待当前保存结束。无持续截图轮询。磁盘/驱动调用仍可能造成等待，未承诺截屏对游戏零影响。

当前面向 SDR 桌面；独占全屏、受保护内容、锁屏/安全桌面、HDR 色彩、多屏不同 DPI/旋转等需要实机验证。截图失败提示与完整保存路径写入 LiteReplay.log。截图功能不依赖 GPU 视频编码器，但精简 Windows 缺少 WIC 系统组件时 PNG 保存可能失败。

## Windows 手动测试（本次未执行）

1. 不开启回放，整屏截图；确认 PNG 可打开、尺寸、颜色、文字和任务栏。
2. 左上到右下及反向框选；核对边缘像素、大小且无选框/提示文字。
3. Esc、右键、Alt+Tab、零面积选择；确认没有多余 PNG、遮罩关闭。
4. 修改两个快捷键并重启；旧键失效，新键有效。设置成相同键、回放键、HUD 键或其它软件占用键时提示，旧注册保持。
5. 主窗口关闭到托盘后执行两种截图。快速连按时不产生无限任务。
6. 中文/空格保存路径、不可写路径、磁盘满；确认成功提示只在文件提交后出现，失败记录原因。
7. 双屏、左侧负坐标屏幕、混合 DPI、旋转显示器；检查框选坐标和实际截图是否一致。
8. 截图时回放同时录制与保存，测试 R5 M320 笔记本及 NVIDIA 主机。统计主进程、截图线程、缩略图子进程及系统媒体资源，不隐藏任何负载。

## Phase2c 剪贴板

两种截图均自动写入 Windows 剪贴板（CF_DIB 24-bit 图像），不是复制文件路径。可在支持图片粘贴的聊天输入框或画图程序按 Ctrl+V。复制会替换原剪贴板内容；取消框选不会改动剪贴板。成功交给系统的图像可在退出 LiteReplay 后继续粘贴，直到被新的剪贴板内容替换。目标应用仍需支持图片粘贴，未保证所有聊天软件都兼容。

剪贴板忙时最多尝试 10 次，每次间隔约 50ms，不用 sleep 阻塞消息线程；失败只提示，不取消 PNG 写入。PNG 写入失败也不撤回已复制的图像。无延迟渲染、不轮询监听剪贴板；完成后关闭重试定时器。粘贴测试应等待“截图已复制”提示，Windows 可能合并/隐藏通知，详细结果见日志。

新增手动验收：整屏/区域分别粘贴到画图和常用聊天窗口，核对方向、颜色、尺寸；截图取消后原剪贴板保持；退出后可粘贴；用其它程序短暂及持续占用剪贴板，确认重试与独立 PNG 保存；PNG 入库一次且文件可打开。上述新项目均待用户实测。
