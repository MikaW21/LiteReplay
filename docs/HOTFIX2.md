# Phase3a Hotfix 2 — 2026-11-10

软件由 Yuzi_Lj 制作 / Software by Yuzi_Lj

## 反馈及修复

用户复测 Hotfix 1 仍出现 0xc00d3702，错误步骤明确为 SetStartStopPosition，预览范围 0 .. 1463333330（100ns）。说明只将结束时间限制到 MFPlay 上报时长仍不足以解决问题；未取得源视频，底层拒绝原因尚未确认。

本版完全取消对 SetStartStopPosition 的调用。播放器打开完整源文件，非零入点使用 SetPosition 定位，滑条和播放头统一使用源文件绝对时间。预览出点由活跃播放时的 100ms 定时器检测并停止。出点停止不是逐帧精确，实际延迟受系统调度影响，不能保证不超过 100ms；导出仍使用原有 FFmpeg 裁剪流程，不受此预览策略影响。自然文件结束由播放器事件处理。

保持时长边界检查、异步打开保护、出错释放资源和日志。窗口标题与侧栏标识 2.0 P3a HF2，便于确认没有误开旧版。

## 测试步骤

1. 从托盘彻底退出旧程序，完整解压新包到新目录。
2. 启动 bin/windows-x64/LiteReplay.exe，确认标题含 P3a HF2。
3. 停止即时回放，导入原报错视频，先测试完整片段播放。
4. 将入点设为非零（例如 20 秒），应用裁剪，播放并拖动到片段中间和结尾。确认播放头显示源文件时间。
5. 片段末尾应自动停止；测试暂停/继续、切换片段、离开剪辑页。
6. 若再次报错，提供新弹窗及 %LOCALAPPDATA%\LiteReplay\2.0\editor-preview.log，说明当时操作。
