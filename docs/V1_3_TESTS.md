# 1.3 验收与限制

## 已执行

Windows x64 交叉编译和链接，便携核心/选项/GPU 聚合/Python 检查器回归测试，原创 WAV 格式/峰值/时长检查，交付包 CRC 与 SHA256 校验。未在 Windows 上运行新版 EXE，未测量悬浮窗性能开销。

## 实机验收

- 退出旧版后解压新版，保留整个 bin/windows-x64，包括 save.wav 与 DLL。
- 开启回放后保存：文件完成写入才响一次。连续保存两段应收到两次完成事件。未开启、重复请求被拒绝、磁盘写入失败均不得播放成功音。
- 关闭提示音后保存应静音（托盘气泡禁用默认声音）；试听按钮允许测试声音。导入 PCM WAV，重启后继续使用；删除自定义音频后试听应报错，保存时回退系统提示声。
- 逐一切换 10 样式、4 个角、3 档透明度；检查 CPU/GPU/RAM 和空值 --。切换与重启后设置保留。
- Ctrl+Shift+F9 切换悬浮窗；按键占用时显示提示，仍可通过设置启用。保存快捷键不能设为该组合。
- 使用窗口化和无边框游戏，检查鼠标点击穿透、不抢焦点、多屏前台窗口切换、Alt+Tab。独占全屏不保证覆盖；不使用进程注入或驱动。
- 主窗口隐藏但悬浮窗显示时继续采样；两者和详细性能窗口全部隐藏后暂停采样。趋势仅保留 60 个样本，采样间断后重新开始。
- 与任务管理器对照趋势；全机 GPU 是最忙引擎，不代表游戏 FPS，不显示未采集的温度/显存/游戏帧率。
- 相同游戏场景比较：程序退出、回放开启但悬浮窗关闭、回放与悬浮窗同时开启。各三轮，记录帧时间、1% low、CPU 和内存，持续两小时检查泄漏。
- 托盘退出后所有窗口消失，音效停止，进程最终退出。

## 音画注意

默认提示音为原创双音，不是 Discord 原版。支持导入用户已有的 Discord WAV 文件，不包含下载器。
提示音由 Windows 默认播放设备播放，系统静音时不能保证可听到；有自定义音量需求可通过 Windows 音量混合器调节。
当前 Desktop Duplication 录制可能包含悬浮窗，WASAPI 可能把提示音录进随后回放；不宣称排除它们。
